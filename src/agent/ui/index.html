03

在网页 AI 中完成授权

尚未验证

在支持远程 MCP 的客户端添加应用，认证方式选择 OAuth。跳转到 Chat2Local 授权页后，粘贴下方生成的一次性配对码。

五分钟有效，仅可使用一次。

添加完成后，在聊天中选中 Chat2Local 并发送：

请使用 Chat2Local 列出我授权的文件夹，不要修改任何文件。

收到真实远端工具调用后，顶部第三步才会标记为已验证。

找不到添加 MCP 应用的入口？

是否支持远程 MCP、OAuth 和写入取决于客户端版本、账号与工作区权限。没有相应入口时，本程序无法代替平台开启。

ChatGPT 用户可查看官方当前说明：开发者模式与 MCP 应用。不要将 Gemini CLI、Kimi Code 的支持情况等同于它们官网聊天页的能力。
