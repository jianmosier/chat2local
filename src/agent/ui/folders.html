完全退出这台电脑？

停止本机客户端并请求停止其命令任务。保留设备身份、共享目录和启动设置，不影响其他电脑。

退出后，重新打开 Chat2Local 启动入口即可连接。关闭网页不等于退出。

完成命令授权

本机已允许执行命令；ChatGPT 连接尚未授予对应权限。

在 ChatGPT 中打开原 Chat2Local 连接，刷新工具清单，按提示授权终端工具。保留原设备和共享目录，无需重新安装。

可用工具、确认提示和菜单位置由账号及工作区策略决定。
