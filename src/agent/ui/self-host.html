入口只需要维护者部署一次

普通使用者

无需安装 ngrok、DevSpace、Node.js 或 Cloudflare 命令行。获得可信管理员提供的连接邀请后，在主面板粘贴，核对入口地址，再连接。

本体验版没有默认公共服务。没有邀请时，可以完整体验本地文件审批，但网页 AI 尚不能访问电脑。这不是网络故障，也不要反复尝试配对。

自行部署的维护者

源码仓库提供 wrangler.jsonc 和 docs/SELF_HOST.md。需要自己的 Cloudflare 账号和部署授权；云服务配额及费用由账号持有人负责。

部署需要设置固定 HTTPS 地址 PUBLIC_ORIGIN、创建 OAuth 存储与设备对象，并安全设置 ENROLLMENT_KEY。不要把注册密钥提交到 GitHub、聊天记录或公开邀请中。

部署完成后先检查 /healthz 和未登录的 /mcp，再进行真实客户端测试。配置文件通过本地构建检查并不代表已经部署到公网。

安全与边界

入口运营者可以接触转发的文件正文。仅授权无敏感信息的测试目录，所有写入仍需本机确认。

当前不提供任意命令行操作，不支持所有文件格式；完整公开服务还需要独立安全审查、运维与滥用防护。
