安装与连接

选择操作

没有实例：使用公开安装入口，登录自己的 Cloudflare 账号并确认创建私人网关；随后在 ChatGPT 添加输出的 /mcp 地址，完成本机目录授权及安装密码设置。

新增电脑：在新电脑执行安装命令并指定原实例地址，在该电脑的浏览器输入实例安装密码，选择目录并确认。旧电脑不必在线，不复制设备凭据，不重复创建 ChatGPT 插件。

已配对电脑：打开已安装的 Chat2Local 入口，复用原身份进入管理页。断网或重启不应默认重新配对。

日常运行

关闭管理网页不停止后台客户端。网络恢复后使用原身份重连；主动退出后重新打开入口。“登录后自动连接”只控制用户登录后的启动。

客户端升级、云端部署和 ChatGPT 工具列表更新分别处理。文件可用但命令待授权时，核对原 OAuth scope、本机命令许可和当前会话工具，不重选已有目录。

权限与安全

支持受限文本文件读写，以及单独授权的 PowerShell/sh 命令。终端不是操作系统沙箱，可以访问共享目录之外的文件、网络并删除文件；文件工具的备份不适用于命令副作用。

每个使用者维护自己的网关。没有默认公共中继，不依赖 DevSpace、Codex、ngrok 或 Google 登录。网关能够接触转发内容。

不要公开安装密码、设备凭据、OAuth 令牌、实际路径或日志。全新第三方账号首装、真实系统重启、应用签名与独立安全审计尚未全部完成。
