Chat2Local 0.1.0-alpha.24

1. 选择入口
首次创建自己的网关：使用源码 README 的普通用户安装命令。
已有实例、新增电脑：使用同一命令并指定自己的 HTTPS 实例地址。
已配对电脑：打开已安装的启动入口，不重新安装或配对。

安装参数填写实例根地址；ChatGPT 应用填写同一地址加 /mcp。
本项目不依赖 DevSpace、Codex、ngrok 或 Google 登录。

2. 新设备配对
在新电脑打开的浏览器输入实例安装密码，选择本机目录并确认。
旧电脑不必在线；不复制设备凭据；不重复创建 ChatGPT 插件。
日常新增目录不需要安装密码。

3. 日常打开
Windows：Win+R，输入 %LOCALAPPDATA%\Chat2Local\Chat2Local.cmd
macOS：终端执行 open "$HOME/Applications/Chat2Local.command"
源码开发：项目目录执行 npm run manage。
此压缩包包含客户端，不会因直接启动就替你创建云端实例。

4. 回连
关闭网页不停止后台程序。断网恢复后，Agent 使用原身份自动重连。
主动退出后重新打开启动入口。
需要系统登录后启动，在“更新与启动”明确开启“登录后自动连接”。
这不是登录前的系统服务，不保证休眠、关机或离线可访问。

5. 权限
文件读写、设备登记、OAuth、终端许可分别检查。
文件可用但命令待授权：检查原连接 scope 与当前会话工具，不重选目录。
终端不是操作系统沙箱，可访问目录外文件、网络并删除文件。
只对可信客户端与明确任务开放。

6. 更新
客户端：使用管理页生成的当前电脑更新命令，保留原实例。
云端：实例所有者部署新版本到原 Worker，不重新创建实例。
ChatGPT 工具列表：按当前账号的正常刷新/审核流程操作。
GitHub 新版不等于云端、所有电脑和工具快照都已更新。

7. 安全
不要公开密码、设备凭据、OAuth 令牌、实际路径、日志或终端输出。
结果未知时先查询原请求，不能盲目重放写入或命令。
