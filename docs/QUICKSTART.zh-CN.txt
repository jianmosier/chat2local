chat2local · 开源私人多设备连接

完整安装后打开 Chat2Local 启动入口；已连接电脑直接进入共享目录管理，不必重新登录或配对。
Mac 的日常入口：~/Applications/Chat2Local.command。
便携包：Windows 运行 start-chat2local.cmd；macOS/Linux 运行 sh start-chat2local.sh。

添加目录：在管理页批量选择真正需要处理的目录，核对每个目录的读写模式，再确认一次。文件保留原位置，不要求使用特定测试目录。已有共享保持不变。
管理页显示的是本机、原连接和实际生效范围。关闭页面不会停止已授权访问；撤销或暂停需明确操作。

新电脑首次连接：使用自己实例提供的安装入口，输入自己的实例安装密码，再选择目录。旧电脑不必在线；不要复制其他设备密钥或传递管理员凭据。
首次部署自己的服务：按 GitHub README 中的公开命令运行配置向导。公开包不会默认连接作者的实例，也不包含作者的配置、设备或密码。

当前支持 64 KiB 内 UTF-8 文本的读取、创建和修改，覆盖前备份及哈希冲突检查。文件工具不提供整盘访问或删除。终端命令属于独立授权：需 terminal:execute 和本机目录终端开关。终端以当前系统用户权限运行，不是目录沙箱，可能访问/修改/删除目录外文件或使用网络；不受普通文件工具的备份保证。

本版本为开发预览。应用签名/公证、全平台与整机重启恢复尚未完整验收。安装错误时保留原配置，不要关闭 TLS/Gatekeeper 或盲目重复授权。具体版本及源码见 BUILD-MANIFEST.json 和公开仓库。
