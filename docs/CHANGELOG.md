# 变更记录

## 0.1.0-alpha.24

### 修复

- 公开发布 `requestBudgetVersion=2`：设备管理轮询与匿名安装请求分离；认证后按设备分别计读取和变更额度，保留实例级防滥用上限。
- 429 返回重试时间；原 OAuth、设备身份和目录授权规则不变。
- 公开检测规则移除维护者具体设备信息，改为通用规则及不导出的私有检测输入；合成测试路径使用中性名称。
- 安装包内置自托管帮助页更新为当前安装、配对和终端边界，移除过期的“无命令执行”说明。

### 文档与发布

- README 按首次创建实例、新增电脑、旧设备恢复、权限诊断和升级组织。
- 统一架构、安装、运维、权限、终端、请求限流和发布文档，并纳入公开清单及 fingerprint。
- 增加公开树及本地已获取 Git 历史的只读脱敏审计入口；结果不输出秘密正文。
- 客户端、云端、安装入口及 ChatGPT 工具快照分别验收；不再把相同版本字符串作为全部同步的证据。

### 兼容性

- 不迁移到 DevSpace，不引入新的本地 MCP 依赖。
- 不自动扩大目录、文件或终端权限，不重置设备身份与启动偏好。
- 不自动改写旧 Git 历史或替换旧 Release 附件。旧引用、缓存和第三方副本不因本次修复而消失。
- 真实 Mac 更新、整机重启、全新第三方账号首装及独立安全审计仍须分别验收。

## 0.1.0-alpha.23

版本化 Windows x64、macOS ARM64、macOS x64 客户端包；稳定管理入口；登录自启设置及升级保留；目录树和命令部分授权状态展示。

原公开版的管理页轮询与匿名 setup 共用限流桶。已部署的单独云端修复可能仍显示 alpha.23，须通过 `requestBudgetVersion=2` 区分；新部署应采用 alpha.24 或之后的已验证版本。
