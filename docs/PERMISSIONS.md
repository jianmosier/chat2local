# 权限与共享范围

适用版本：0.1.0-alpha.24。

## 1. 权限交集

```text
文件访问 = OAuth scope ∩ 当前连接共享范围 ∩ 本机目录策略
命令执行 = terminal:execute ∩ 当前连接/目录 ∩ 本机明确命令许可 ∩ 直接可写共享
```

本机允许不等于 OAuth 已授权，服务器有工具不等于当前 ChatGPT 会话已加载。普通文件工具不能调用本机管理 API 扩大权限。

| 模式 | 文件读取 | 文件写入 | 命令执行 |
| --- | --- | --- | --- |
| 只读 | 需要读取 scope | 不允许 | 不允许 |
| 逐次审批 | 需要读取 scope | 提案经本机批准后提交 | 不允许 |
| 直接读写 | 需要读取 scope | 需要 `files:write` 和本机 direct 权限 | 不自动允许 |
| 完整共享 | 按对应 scope | 按对应 scope | 另需 `terminal:execute`；本机确认已包含命令风险 |

`propose_write` 即使在直接可写目录中仍是提案，不能把 pending 当作写入成功。`write_file` 创建时 `expectedHash=null`；覆盖时使用当前 `read_file` 返回的哈希。

## 2. 命令状态

| 状态 | 含义 | 操作 |
| --- | --- | --- |
| 本机命令许可关闭 | 该目录尚未允许远程命令 | 在本机管理页核对风险后明确启用 |
| 可读写 · 命令待授权 | 本机已允许，但旧 OAuth 缺少命令 scope | 完成原连接的正常授权，并核对平台工具列表 |
| 已授权但会话没有终端工具 | 平台/会话工具快照尚未更新 | 按平台支持的刷新流程处理 |
| `terminalAllowed=true` | 当前调用的许可交集成立 | 仍须有明确任务意图，不能任意执行命令 |
| 未读取/未知 | 状态查询未成功或不完整 | 保留未知，不显示成已授权 |

新增权限不会因页面轮询、客户端更新、重新联网或换版本而自动获得。原有只读、逐次审批和文件-only 共享不会自动升级。

## 3. 父子目录与撤销

| 操作 | 当前规则 |
| --- | --- |
| 父目录能力完全覆盖子目录 | 界面折叠子项，保留其独立授权记录 |
| 子目录拥有更高权限 | 保留可见独立子项 |
| 移除父目录共享 | 保留有效的独立子目录授权 |
| 移除子目录共享，但父目录仍覆盖它 | 确认框列出影响；同时撤销覆盖它的父目录共享，避免产生虚假的“已取消访问”状态 |
| 云端暂时不可用 | 本机先撤销，保存原请求，重连后同步；不恢复已经撤销的许可 |

“移除共享”不删除磁盘文件，不回滚已运行命令的副作用。只要其他共享仍允许非沙箱终端，该命令可能继续访问目录外路径；不能把撤销一个文件工具目录等同于操作系统级隔离。

## 4. 终端风险

终端以桌面用户权限运行，可能修改或删除 cwd 之外的文件、访问网络、启动脱离进程树的子进程。超时或取消不能保证所有脱离的子进程结束，也不会回滚文件改动。撤销 OAuth 不一定立即终止已在本机运行的任务。

命令环境经过限制，但同一操作系统用户可以读取的秘密仍可能被命令访问。需要更强隔离时，应使用独立操作系统用户或经过验证的沙箱方案；本项目不声称已实现它们。

## 5. 凭据管理

实例安装密码用于新增设备；本机控制会话用于管理；OAuth 用于 ChatGPT 能力；设备密钥用于设备认证。四者不能相互替代。

密码、令牌、设备身份、真实目录、日志与命令输出不能进入公开仓库。脱敏与历史检查见 [RELEASE.md](RELEASE.md)。
